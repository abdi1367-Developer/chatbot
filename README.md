# 🤖 دستیار هوشمند مرکز مبادله ارز و طلای ایران

چت‌بات حرفه‌ای فارسی (RTL) که پاسخ سؤالات متداول را از فایل `data.json` استخراج می‌کند.
بدون نیاز به دیتابیس، سرویس جانبی یا زیرساخت خاص؛ کاملاً روی **Vercel** قابل استقرار است.

---

## 🎨 رنگ‌های برند

پالت سایت روی دو رنگ رسمی شما بنا شده است (در `tailwind.config.ts`):

| نقش | مقدار | کلاس Tailwind |
| --- | --- | --- |
| سرمه‌ای نفتی (اصلی) | `rgb(0, 68, 84)` = `#004454` | `brand-700` (و مقیاس `brand-50…950`) |
| سبز فیروزه‌ای (تأکیدی) | `rgb(70, 178, 152)` = `#46B298` | `accent-500` (و مقیاس `accent-50…950`) |

برای تغییر رنگ‌ها فقط همان دو بلوک در `tailwind.config.ts` را ویرایش کنید.

## ✨ امکانات

- **جریان احراز هویت گفتگو (Lead Capture):** ابتدا نام و سپس شماره تماس کاربر دریافت می‌شود.
- **منوی انتخاب موضوع داخل چت:** موضوعات به‌صورت دکمه‌های شماره‌دار در حباب پیام؛
  انتخاب موضوع ← فهرست پرسش‌های همان موضوع ← پاسخ + منبع رسمی.
- **موتور جست‌وجوی اختصاصی فارسی (حساس به واژگان):**
  - نرمال‌سازی نویسه‌های عربی/فارسی، نیم‌فاصله و اعداد فارسی/عربی
  - ریشه‌یابی سبک (حذف پسوندهای «ها»، «های»، «تر»، «ی»، «ه» و…)
  - **IDF به سبک BM25** → واژه‌های کلیدی متمایزکننده وزن بسیار بیشتری می‌گیرند
  - **ایندکس معکوس + ایندکس سه‌نویسه** → جست‌وجوی فوری حتی با صدها پرسش
  - **تطابق فازی** برای تحمل غلط‌املایی (`تسویه` ≈ `تسوییه`)
  - **دونگاره‌ی متوالی ریشه‌ها** → تفکیک پرسش‌های بسیار مشابه
    (مثلاً «تسویه نقدی» از «تسویه مدت‌دار»)
- **پاسخ در چهار سطح اطمینان:**
  1. تطابق قطعی → پاسخ + پرسش‌های مرتبط
  2. تطابق نزدیک → **پاسخ داده می‌شود** و پرسش‌های نزدیک هم پیشنهاد می‌گردد
  3. اطمینان کم → فهرست نزدیک‌ترین پرسش‌ها به‌صورت دکمه
  4. بدون تطابق → پیام راهنما + نزدیک‌ترین گزینه‌ها + شماره پشتیبانی
- **بخش «پرسش‌های پرتکرار» دسته‌بندی‌شده در سایت:** نوار تب موضوعات + **۶ پرسش پرتکرار
  از هر موضوع** به‌صورت آکاردئون، همراه با منبع و دکمه‌ی «مشاهده همه پرسش‌های این موضوع در گفتگو».
  (تعداد را با `bot.config.ts → ui.faqPerCategory` تغییر دهید.)
- **نمایش منبع رسمی** برای هر پاسخ.
- **رابط کاربری حرفه‌ای:** ویجت شناور، نشانگر تایپ، حباب پیام، پاسخ‌های سریع،
  ذخیره‌سازی گفتگو در `localStorage`، ریسپانسیو کامل (فول‌اسکرین در موبایل).
- **انیمیشن‌های آرام:** ظاهر شدن تدریجی بخش‌ها هنگام اسکرول (`Reveal`)،
  هاله‌های نورانی متحرک (aurora)، و پشتیبانی از `prefers-reduced-motion`.
- **کارایی:** نیازی به LLM یا API بیرونی ندارد.
- **اختیاری:** اتصال به وب‌هوک برای ثبت سرنخ‌ها و بازنویسی پاسخ با مدل زبانی (LLM).

## 🖼️ جای لوگو (مهم)

فایل لوگوی خود را در پوشه‌ی **`public/`** قرار دهید (نام پیشنهادی: **`logo.png`**).

لوگو در **چهار جا** استفاده می‌شود: هدر صفحه‌ی فرود، فوتر، هدر پنجره‌ی چت
و آواتار پیام‌های ربات و همچنین favicon.

### ⚠️ اگر لوگو نمایش داده نشد

مهم‌ترین علت: **پسوند فایل با فرمت واقعی آن هم‌خوان نیست**
(مثلاً یک تصویر PNG که نام آن `logo.svg` گذاشته شده). در این حالت سرور فایل را با
`Content-Type` اشتباه می‌فرستد و مرورگر قادر به نمایش آن نیست.

خوبی ماجرا: پروژه این مشکل را **خودکار** حل می‌کند.
اسکریپت `scripts/prepare-logo.mjs` پیش از `npm run dev` و `npm run build` اجرا می‌شود،
فرمت واقعی فایل را از روی امضای باینری تشخیص می‌دهد و در صورت نیاز یک کپی با پسوند
صحیح می‌سازد:

```bash
npm run logo      # اجرای دستی اسکریپت (اختیاری)
```

همچنین کامپوننت `BrandLogo` چند مسیر را به‌ترتیب امتحان می‌کند
(`/logo.png` → `/logo.svg` → `/logo.jpg` → `/logo.webp` → …) و اگر هیچ‌کدام
باز نشد، یک نشان پیش‌فرض طلایی‌سرمه‌ای نمایش می‌دهد؛ بنابراین سایت هرگز بدون لوگو نمی‌ماند.

اگر نام فایل شما چیز دیگری است، فقط کافی است مسیر آن را در
`src/config/bot.config.ts` تنظیم کنید:

```ts
branding: {
  logo: "/logo.png",          // ← مسیر نسبت به پوشه public
  logoSources: ["/logo.png"], // ← مسیرهای جایگزین
  ...
}
```

> پیشنهاد: فایل PNG با پس‌زمینه‌ی شفاف و اندازه‌ی حداقل ۲۵۶×۲۵۶ پیکسل.

## 🧠 ویرایش دانش‌نامه

فقط فایل `data.json` را ویرایش کنید. ساختار هر آیتم:

```json
{
  "id": 1,
  "category": "حراج سکه طلا",
  "question": "…؟",
  "answer": "…",
  "source": "https://…"
}
```

> نشانگرهای داخلی مثل `[reference:22]` به‌صورت خودکار از پاسخ‌ها حذف می‌شوند.

برای افزودن دسته‌بندی جدید، کافی است در همان فایل `category` بنویسید و
نام آن را به `quickCategories` در `src/config/bot.config.ts` اضافه کنید.

## 💾 ثبت سرنخ‌ها (نام و شماره تماس)

به‌صورت پیش‌فرض هر سرنخ در **لاگ سرور** ثبت می‌شود
(Vercel → Project → Logs → عبارت `[chatbot][lead]`).

برای ارسال به CRM/ERP/اسلک/گوگل‌شیت، متغیر زیر را در Vercel تنظیم کنید:

```
LEAD_WEBHOOK_URL=https://…
```

قالب داده‌ای که POST می‌شود:

```json
{
  "type": "chatbot_lead",
  "name": "علی رضایی",
  "phone": "09121234567",
  "sessionId": "…",
  "source": "مرکز مبادله ارز و طلای ایران",
  "createdAt": "2026-01-01T00:00:00.000Z"
}
```

## 🔌 اتصال اختیاری به مدل زبانی (LLM)

پاسخ‌های موتور محلی کاملاً دقیق و مبتنی بر منابع هستند. اگر می‌خواهید
پاسخ‌ها روان‌تر بازنویسی شوند (با حفظ صحت و فقط بر اساس متن مرجع)،
این متغیرها را تنظیم کنید:

```
ENABLE_LLM=true
OPENAI_API_KEY=sk-…
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

اگر این بخش را فعال نکنید، چت‌بات همچنان کامل کار می‌کند.

## ☁️ استقرار روی Vercel

### روش ۱ — از طریق GitHub (پیشنهادی)

**گام ۱: اصلاح نام لوگو (مهم)**

فایل `public/logo.svg` شما در واقع یک تصویر **PNG** است. حتماً آن را به
`public/logo.png` تغییر نام دهید (هم برای نمایش درست در مرورگر، هم برای اینکه
Git با تبدیل خطوط، فایل دودویی را خراب نکند):

```powershell
Rename-Item .\public\logo.svg .\public\logo.png
```

> اگر Node نصب است، `npm run logo` هم همین کار را خودکار انجام می‌دهد.

**گام ۲: Push به GitHub (یک کلیک)**

اسکریپت آماده در پروژه هست:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\push-to-github.ps1
```

این اسکریپت به‌ترتیب: بررسی نصب Git ← اصلاح لوگو ← `git init` (در صورت نیاز) ←
تنظیم هویت ← افزودن remote ← commit ← push را انجام می‌دهد.

اگر ترجیح می‌دهید دستی انجام دهید:

```powershell
git init
git branch -M main
git remote add origin https://github.com/abdi1367-Developer/chatbot.git
git add -A
git commit -m "feat: smart chatbot"
git push -u origin main
```

> **احراز هویت GitHub:** رمز عبور کار نمی‌کند. یا از
> [Personal Access Token](https://github.com/settings/tokens) (با دسترسی `repo`)
> استفاده کنید، یا یک‌بار `git config --global credential.helper manager` را اجرا
> کنید تا پنجره‌ی ورود مرورگر باز شود.

**گام ۳: Import در Vercel**

1. به [vercel.com/new](https://vercel.com/new) بروید.
2. **Import Git Repository** ← ریپوی `chatbot` را انتخاب کنید.
3. Vercel خودش Next.js را تشخیص می‌دهد؛ فقط **Deploy** را بزنید.
4. (اختیاری) در **Settings → Environment Variables** متغیرهای `.env.example` را وارد کنید.

### روش ۲ — با CLI

```bash
npm i -g vercel
vercel        # پیش‌نمایش
vercel --prod # انتشار نهایی
```

> هیچ تنظیم اضافه‌ای لازم نیست: نه دیتابیس، نه سرویس خارجی و نه build command خاص.
